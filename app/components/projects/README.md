# Страницы проектов

Все детальные страницы используют маршрут `/projects/[slug]` и компонент
`ProjectDetails`. Значение `slug` соответствует полю `id` в `projects.ts`.
Неизвестные проекты возвращают 404. Страницы создаются при сборке сайта.

Чтобы добавить проект:

1. Создайте файл в `data/` по примеру `image-converter.ts`.
   Добавьте версии `ru` и `en` с типом `Record<SupportedLanguage, ProjectCaseStudy>`.
2. Добавьте запись в массив `projects` в `projects.ts`: уникальный `id`,
   `href` вида `/projects/ваш-id`, название, стек, обложку, тексты карточки
   на двух языках и ссылку `caseStudy` на подготовленные данные.
3. Положите изображения в `public/images/projects/ваш-id/` и укажите их размеры
   и переведённые альтернативные описания.

Разделы каждого проекта могут отличаться. Поле `sections` задаёт их порядок,
заголовки и содержание. `id` раздела должен быть уникальным в пределах страницы
и совпадать в обеих языковых версиях; он используется для якорей содержания.

Типы блоков описаны в `project-types.ts`:

- `paragraph`: абзац текста.
- `list`: нумерованный или обычный список; выделенный заголовок пункта необязателен.
- `image`: изображение с необязательной подписью.
- `decisions`: набор технических решений с заголовками и описаниями.

Язык кейса переключается через общий переключатель сайта и сохраняется
в настройках браузера. SEO-метаданные формируются из русской версии при сборке:
языки используют один URL, а переключатель меняет содержимое в браузере.
